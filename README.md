# Инженерная практика больших языковых моделей — том 1

Программное сопровождение книги. Версия 1.0.0 от 14 октября 2026 года.
Адрес: https://github.com/MaytakRoman/llm-engineering-vol1

## Быстрый запуск

Нужны Python 3.12.14 и NumPy 2.3.5. GPU, сетевые API и внешние датасеты не требуются.
Из распакованного каталога выполните:

```sh
python -m pip install -r requirements.txt
python run_all.py
```

На macOS/Linux вместо `python` может требоваться `python3`.
Полный запуск сначала выполняет `case_experiment.py`, затем 36 листингов глав.
Листинг 12.1 читает веса, полученные в приложении А.1, поэтому его запускают после опыта.
Каждый листинг можно выполнить отдельно, например `python ch01_listing01.py`.
Повторный запуск обновляет результаты и журналы. Для сохранения старого опыта копируйте весь каталог.

## Состав

- `chNN_listingMM.py` — 36 листингов глав 1–12, извлечённых из рукописи без изменения кода.
- `case_experiment.py` — полный синтетический опыт приложения А.1: генерация, обучение, проверка, сохранение весов.
- `LISTINGS.md` — соответствие 37 листингов файлам.
- `run_all.py` — последовательный запуск в отдельных процессах с журналами и кодами завершения.
- `results/` — JSON-отчёты опытов и `case_weights.npz`.
- `execution_logs/` — полный вывод каждой программы.
- `execution_report.json` — фактические коды завершения, длительности и вывод.
- `SHA256.json` — контрольные суммы файлов комплекта, кроме самого манифеста.
- `requirements.txt` — фиксированная зависимость.
- `toy_pipeline/` — синтетический корпус главы 3: обучающая и тестовая выборки, журнал решений и сводный отчёт обработки.

Каталоги data/, configs/, training/, evaluation/ и service/ в таблице А.1 книги
относятся к рекомендуемой архитектуре расширенного проекта. В учебном комплекте
листинги находятся в корне, результаты — в results/.

## Проверка и границы применимости

Все 37 извлечённых программ исполнены на Linux, Python 3.12.14, NumPy 2.3.5.
Фактические результаты сохранены в execution_report.json; проверка на Windows и macOS не выполнялась.
Код содержит учебные численные модели, малые эталоны и синтетические данные.
Он не обучает промышленную LLM и не измеряет реальную производительность GPU или сети.
Малый синтетический тест не подтверждает перенос на реальные обращения.
Контроллер главы 12 имеет узкую область действия; на диагностическом наборе
он передаёт все обращения оператору. Нулевой охват не является доказательством качества классификации.
Численные результаты могут немного различаться между реализациями BLAS и платформами.
Хеш канонического корпуса проверяют точно; вещественные метрики — с обоснованным допуском.
